# Copywriting - construction encadree pour diaspora

Date : 2026-06-03

## Pivot strategique

Le site ne doit pas vendre une entreprise BTP generique.

La vraie douleur a adresser :

> Beaucoup de membres de la diaspora veulent construire une maison dans leur
> pays d'origine, mais ils sont loin. Ils ont peur d'envoyer de l'argent sans
> controle, de ne pas voir l'avancement reel, ou de se retrouver avec un
> chantier qui n'est jamais termine.

Le bon angle :

```text
Construire au pays depuis l'etranger, avec un chantier encadre,
des preuves d'avancement et des paiements par etapes validees.
```

## Bon vocabulaire

Utiliser :

- `construction encadree` ;
- `construction cle en main encadree` ;
- `suivi de chantier a distance` ;
- `paiement par etapes validees` ;
- `reporting photo et video` ;
- `responsable de chantier unique` ;
- `budget trace` ;
- `devis detaille` ;
- `planning visible` ;
- `validation avant decaissement` ;
- `maitrise d'ouvrage deleguee` ;
- `chantier suivi, pas chantier a l'aveugle`.

Eviter :

- `votre famille mange l'argent` dans le texte public ;
- `zero risque` ;
- `argent garanti` ;
- `on protege votre argent` si aucun cadre juridique / sequestre n'est en
  place ;
- les accusations directes contre la famille ou les artisans.

Formulation plus professionnelle :

```text
Ne construisez plus a distance avec des promesses seules.
Avancez avec un contrat, un planning, des preuves et des paiements par etapes.
```

## Section probleme

Titre :

```text
Le probleme n'est pas seulement de construire. C'est de construire a distance.
```

Texte :

```text
Quand vous vivez loin du chantier, chaque decision devient plus difficile : qui
achete les materiaux, qui suit les ouvriers, qui verifie les factures, qui
prouve que l'argent envoye avance vraiment la maison ?
```

Cartes :

```text
Argent envoye, preuves insuffisantes
Des photos rares, des explications floues et un budget qui part sans vision
claire.

Chantier bloque sans alerte
Un retard peut rester invisible pendant des semaines quand personne ne vous
rend compte.

Decisions prises trop loin de vous
Materiaux, finitions, priorites : tout peut changer si le projet n'est pas
cadre.
```

## Section solution

Titre :

```text
Une construction cle en main encadree pour la diaspora.
```

Texte :

```text
Nous ne vous demandons pas de croire sur parole. Le projet avance par etapes :
diagnostic, devis, contrat, planning, achats valides, photos, videos et points
de suivi.
```

Points :

```text
Contrat et devis avant travaux
Chaque poste est liste : gros oeuvre, toiture, plomberie, electricite,
finitions et delais.

Paiements par jalons
Le budget avance selon les etapes validees, pas en un seul versement sans
controle.

Reporting photo et video
Vous recevez des preuves regulieres de l'avancement reel du chantier.

Responsable unique
Une personne suit votre dossier et centralise les decisions importantes.
```

## Section methode

Titre :

```text
Comment votre maison avance, meme si vous etes loin.
```

Etapes :

```text
1. Vous decrivez votre projet
Terrain, quartier, surface, type de maison, budget cible et delai souhaite.

2. Nous validons la faisabilite
Visite terrain, contraintes, acces, materiaux, premieres estimations.

3. Vous recevez un devis detaille
Budget par poste, planning previsionnel et conditions de paiement.

4. Le chantier avance par etapes
Chaque jalon est documente avant la suite : fondations, murs, toiture,
reseaux, finitions.

5. Vous suivez a distance
Photos, videos, compte rendu et prochaines decisions a valider.
```

## Formulaire de conversion

Titre :

```text
Faites evaluer votre projet de construction a distance.
```

Sous-texte :

```text
Expliquez votre projet. Nous revenons vers vous pour verifier la faisabilite,
les etapes, le budget cible et le niveau de suivi necessaire.
```

Champs :

- nom ;
- pays de residence ;
- telephone / WhatsApp ;
- email ;
- ville ou quartier du terrain ;
- terrain deja disponible : oui / non / en cours ;
- type de projet : maison familiale, villa, extension, renovation, local ;
- surface estimee ;
- budget indicatif ;
- delai souhaite ;
- niveau d'accompagnement souhaite :
  - devis seulement ;
  - suivi chantier ;
  - construction cle en main encadree ;
- message ;
- photos ou documents du terrain si disponible.

CTA :

```text
Demander une premiere evaluation
```

Message de confirmation :

```text
Votre demande a bien ete recue. Un responsable vous contactera pour clarifier
le projet, les contraintes du terrain et les prochaines etapes avant tout devis
final.
```

## Angle visuel pour les prochaines maquettes

Les maquettes doivent montrer :

- une maison en construction / renovation avec vraie presence humaine ;
- une interface ou carte de suivi sobre : `Fondations validees`, `Toiture en
  cours`, `Photos recues`, sans trop de texte dans l'image ;
- des preuves photo/video ;
- un tableau de jalons de paiement ;
- une section diaspora ouverte : Europe, Amerique du Nord, Afrique, Ocean
  Indien, Moyen-Orient ;
- un formulaire oriente projet a distance.

Ne plus utiliser de blocs abstraits sans image. Le rendu doit rester proche de
MadaVoyage et Garage : photographie forte, sections nettes, offres concretes,
conversion credible.
